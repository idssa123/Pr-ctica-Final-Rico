# Proyecto: Práctica Final Rico

Este repositorio contiene el archivo `Main.java` del proyecto.

Instrucciones rápidas:

- Compilar: `javac Main.java`
- Ejecutar: `java Main`

Pasos para subir al repositorio remoto en GitHub:

1. Crear un repositorio vacío en GitHub (sin README).
2. Añadir el remote y hacer push:

```
git remote add origin https://github.com/USUARIO/NOMBRE_REPO.git
git branch -M main
git push -u origin main
```

O usar la CLI de GitHub (si tiene `gh` autenticado):

```
gh repo create NOMBRE_REPO --public --source=. --remote=origin --push
```
